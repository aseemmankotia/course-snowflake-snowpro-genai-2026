## Chapter 12 Cheat Sheet: Full Exam Simulation & Time Management

### Approximate Exam Format (verify official guide)
| Item | Approximate Value |
|---|---|
| Question count | ~65 |
| Total time | ~85 minutes |
| Time per question | ~1.3 min |
| Passing scaled score | ~750 / 1000 |
| Recommended end-of-exam review buffer | 5-10 min |

### Time Budget Rule
- Conceptual/definition Qs → answer fast, bank time.
- Scenario Qs (multi-paragraph) → spend more time, use elimination technique.
- Never let one question exceed ~2x its budgeted time — flag and move on.

### Elimination Strategy: Find the Constraint Sentence
1. Scan scenario for the ONE hard constraint: cost cap, latency, data residency, "no external calls", compliance requirement.
2. Eliminate any option that violates that constraint — usually removes 2 of 4 choices.
3. Compare remaining 2 options against secondary requirements (cost, complexity, deprecated service).

### Cortex Feature Q vs Generic Gen AI Theory Q
| Signal | Cortex/Platform Question | Generic Theory Question |
|---|---|---|
| Wording | Names a specific in-platform function (e.g., CORTEX.COMPLETE, CORTEX.SUMMARIZE, CORTEX.EXTRACT_ANSWER) | Describes concepts abstractly (embeddings, transformers, fine-tuning) |
| Answer source | Product documentation / syntax | General ML/AI theory |
| Trap | Don't answer with generic ML knowledge if a function name is present | Don't invent a platform feature that wasn't mentioned |

### Flagging & Review Workflow
1. **Pass 1:** Read question → find constraint → eliminate → answer with best guess → flag if unsure → move on. Never skip/blank.
2. **Buffer checkpoint:** At ~10 min remaining (or your set buffer), stop new questions.
3. **Pass 2:** Go only to flagged questions, re-apply elimination with fresh eyes, finalize each answer.

### Scaled Score Reminder
- Scaled score (~750/1000 to pass) is NOT a raw percentage — don't equate a 700 scaled score to "70% correct."
- Domain-level reporting on practice exams should drive your final review priorities, not overall score alone.

### Pre-Exam Weak-Spot List
1. List every domain from the course outline.
2. Record your self-assessed / practice score per domain.
3. Rank lowest to highest.
4. Allocate remaining study time to the bottom 2 domains before scheduling.

### Commonly Missed Traps
- Assuming exam format numbers are fixed and official without checking the current guide.
- Treating scaled score as a direct raw percentage.
- Answering Cortex-syntax questions using generic AI theory instead of platform-specific docs.
- Leaving flagged questions unchanged instead of re-answering during the review pass.
